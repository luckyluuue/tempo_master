# PolyPulse Practice

Language: [日本語](docs/README.ja.md) / [English](docs/README.en.md) / [Español](docs/README.es.md)

Open the app:

https://luckyluuue.github.io/tempo_master/

PolyPulse Practice is a small PWA for practicing Debussy Arabesque No.1 rhythm excerpts, polyrhythms, and metronome subdivisions.

The app is available in:

- Japanese: https://luckyluuue.github.io/tempo_master/ja/
- English: https://luckyluuue.github.io/tempo_master/en/
- Spanish: https://luckyluuue.github.io/tempo_master/es/

The root URL automatically redirects based on the browser language.
